# 📌 Overview

The **AI Career Guidance Assistant** is a Generative AI-based application designed to help engineering students identify suitable career paths and understand what they need to learn to become industry-ready.

The application analyzes a student's:

- Engineering branch
- Academic year
- Current technical skills
- Preferred career role
- Existing projects
- Learning hours per day
- Preferred language

Based on this information, the system provides:

- Career-role recommendations
- Skill-match analysis
- Skill-gap identification
- Personalized learning recommendations
- 30/60/90-day learning roadmap
- Project recommendations
- Career-related Q&A
- Multilingual AI responses
- AI-generated voice output

The system combines deterministic career matching with Generative AI to provide personalized guidance instead of generic chatbot responses.

- Which career path is suitable for them
- Which technical skills they should learn
- Which skills they are currently missing
- Which projects they should build
